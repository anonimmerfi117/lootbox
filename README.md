# LOOTBOX — игровой маркет в Telegram (демо)

Демо-магазин игровых товаров в Telegram: бот + мини-приложение. Показывает, как автоматизировать тг-шоп от витрины до выдачи товара.

## Что умеет

**Покупатель**
- Каталог по играм и разделам: аккаунты, валюта, предметы, ключи, буст, пополнения, девайсы и мерч
- Поиск, карточки товаров, отзывы и рейтинг
- Хиты всегда первыми, сортировка «Сначала дешёвые»
- Обучение для новых покупателей при первом открытии
- Профиль: статистика покупок, любимая игра, последние заказы, выбор темы (авто / светлая / тёмная)
- «Вопросы и ответы» с поиском и чат с поддержкой; написать в поддержку можно и прямо боту
- Мягкие анимации нажатий
- Поля «что указать продавцу» (UID, ссылка на обмен, размер)
- Корзина синхронизируется между устройствами через облако Telegram
- Два способа оплаты:
  - ⭐ Telegram Stars — для цифровых товаров;
  - ₿ крипта (USDT, TON, BTC через CryptoBot) — для всех товаров, цены в $
- Промокоды
- **Мгновенная выдача**: после оплаты открывается окно «Лут получен» с данными и кнопками «Копировать», копия приходит в чат с ботом
- **Демо-режим**: любой товар выдаётся сразу, вместо настоящих данных — «Тест» (константа `DEMO_AUTODELIVERY` в `worker.js`)
- **Гарантия сделки**: «Подтвердить получение» или «Открыть спор»; без подтверждения заказ закрывается сам через 72 часа
- Чат с продавцом внутри заказа; можно отвечать прямо в боте через Reply
- Статусы заказа с уведомлениями

**Владелец**
- Уведомление о каждой продаже с кнопкой «Открыть заказ»
- Сводка: выручка по способам оплаты, график за 7 дней, топ продаж, свежие отзывы
- Выдача аккаунтов и услуг, трек-номера для доставки
- Возврат звёзд одной кнопкой
- Товары: поиск, быстрое скрытие переключателем, редактор с живым предпросмотром, склад ключей (вставить пачкой)
- Предупреждение «заканчиваются ключи»
- Промокоды с лимитом использований, рассылка по всем пользователям
- Ссылка на конкретный товар для постов в канале
- Люди: список пользователей, карточка с заказами и всеми действиями, общая лента действий (хранится 90 дней)
- Назначение администраторов прямо из приложения (только владелец)
- Поддержка: все обращения в одном списке, ответ из приложения или реплаем в боте

**Обязательная подписка на каналы**
- Пока человек не подписан на все каналы, бот ничего не делает, а присылает кнопки-ссылки на недостающие каналы и «✅ Я подписался»; в маркете вместо витрины — экран «Подпишитесь на каналы» с кнопкой «Проверить подписку» (и автопроверкой при возврате из канала)
- Проверка через `getChatMember`, все каналы одновременно; «подписан» запоминается на 7 минут, «не подписан» — нет. Отписался — после 7 минут бот снова попросит подписаться
- Админы бота проверку не проходят; оплата, начатая до проверки, не блокируется
- Если бот не администратор канала или канал пропал, канал пропускается (людей им не блокируем), а админам один раз приходит уведомление с причиной; когда права вернут — «снова работает»
- Каналы хранятся в базе. Управление → «Каналы»: включить/выключить проверку, список со статусом, добавить (@username, ссылка t.me/…, или ID -100… + ссылка-приглашение для приватного), удалить
- То же командами для админов: `/channels`, `/addchannel`, `/delchannel`, `/subcheck on|off`. Переслал боту пост из приватного канала — бот присылает его ID и готовую команду
- Статистика: сколько людей упёрлось в проверку и сколько подписалось после неё (в Сводке, во вкладке «Каналы» и в /channels); всё попадает и в ленту действий

**Бот**
- Сообщения с премиум-эмодзи из пака `tgmacicons` и цветными кнопками (нужен Telegram Premium у владельца бота); без Premium бот сам переходит на обычные эмодзи
- `/emoji` (владелец): какие значки заменяются, `/emoji ✅ 12` — поставить свой значок из пака

## Состав
- `index.html` — мини-приложение (GitHub Pages)
- `worker.js` — бот и API (Cloudflare Workers + база D1)

## Переменные воркера
| Имя | Тип | Что это |
|---|---|---|
| `BOT_TOKEN` | Secret | токен бота из @BotFather |
| `APP_URL` | Text | адрес мини-приложения |
| `OWNER_ID` | Text | Telegram ID владельца |
| `ADMIN_IDS` | Text | ID помощников через запятую (необязательно) |
| `CRYPTO_PAY_TOKEN` | Secret | токен приложения из @CryptoTestnetBot (необязательно) |
| `CRYPTO_TESTNET` | Text | `0` — настоящая сеть CryptoBot; по умолчанию тестовая |

Привязка D1: имя `DB`.

Крипта для цифровых товаров включается константой `CRYPTO_FOR_DIGITAL` в начале `worker.js`. Telegram требует оплату цифрового в звёздах, поэтому для публичного бота её лучше выключить.
